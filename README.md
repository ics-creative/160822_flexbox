# Flexbox入門デモ

Flexboxでヘッダーとカードレイアウトを作るためのデモコードです。

解説記事: [Flexbox入門 - 横並びを実現する定番のCSS](https://ics.media/entry/13117/)

## デモ

`docs/` 内のHTMLをブラウザで開くと確認できます。

- [`docs/1_layout.html`](docs/1_layout.html): Flexboxによる基本レイアウト
- [`docs/2_responsive.html`](docs/2_responsive.html): メディアクエリーを使ったレスポンシブ対応
- [`docs/3_complete.html`](docs/3_complete.html): 完成版

## 使い方

このリポジトリはビルドなしで動作します。次のいずれかを直接ブラウザで開いてください。

```text
docs/1_layout.html
docs/2_responsive.html
docs/3_complete.html
```
